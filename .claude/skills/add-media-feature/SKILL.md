# Add a media feature

Read first: `.claude/rules/media.md`, `external.md`.

## Steps

1. Keep originals private and immutable. Derivatives are generated by the Worker.
2. Uploads and URL fetches pass type sniffing, size limits, malware scanning, and (for URLs) the SSRF-safe
   fetcher before acceptance.
3. Strip EXIF location. Respect focal points when cropping.
4. Update usage tracking and quota accounting through the entitlements facade.
5. Rendering changes go through `add-theme-component`.

## Checklist

- [ ] Tests with malicious files (polyglots, oversized, wrong extension).
- [ ] SSRF tests for URL fetches (private IPs, redirects, DNS rebinding).
- [ ] Two-site test for media access.
