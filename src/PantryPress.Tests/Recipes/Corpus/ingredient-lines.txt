# The ingredient-line corpus (RCP-002; PP4.5): what IngredientLineParser reads from lines bloggers really write.
#
# Each case is two lines. The first is "> " and the line exactly as written (">" alone is the empty line); a
# backslash and u with four hex digits, or two backslashes, are its only escapes, for characters an editor would hide
# or trim. The second is "= " and the parse:
#   unparsed <problem>
#   parsed | <quantity> | <unit> | item "<text>" | note "<text>"
# where <quantity> is - (none), n/d, low..high, or to-taste, each with @start+length, its span in UTF-16 code units;
# <unit> is - or its vocabulary code with its span; and an absent note is "note -". Quoted text escapes \, ", and anything
# invisible as above.
#
# Every expectation here was read and approved by hand. Nothing rewrites this file: when the parser's answer for a line
# changes on purpose, that line is edited, and the change says why (CLAUDE.md: golden files are never re-approved in bulk).
